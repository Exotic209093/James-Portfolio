# Social image fonts

Static instances used only by `app/opengraph-image.tsx`, kept in the repo so the
build never depends on fetching fonts.

- `archivo-expanded-semibold.ttf`: Archivo, width 125, weight 600
- `archivo-regular.ttf`: Archivo, weight 400
- `jetbrains-mono-medium.ttf`: JetBrains Mono, weight 500

Both families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org) and were downloaded from Google Fonts.
